Page Turner

Page Turner is a native macOS reader for source material that usually gets split across too many tools. It treats books, screenplay files, sheet music, archive-backed page sets, WebM and Matroska media, Photoshop documents, YAML collections, and 3D assets as first-class reading and viewing experiences inside one app.

What Makes PageTurner Different

  • One reader spans radically different formats. Page Turner handles ebooks, comics, scripts, scores, media, and model files without forcing each category into a separate app or browser tab.
  • Large parts of the stack are native and self-contained. Page Turner includes its own ZIP read/write path, in-process archive extraction for RAR, 7z, and TAR variants, custom readers for Kindle, FB2, XPS, screenplay formats, MusicXML, YAML, and Photoshop, plus dedicated WebM and Matroska playback paths.
  • Media features stay local. Video live captions run on-device after installing a Whisper Core ML model into the app, and current video frames can be captured directly to PNG.
  • Folders and archives become readable books. Image folders, HTML folders, YAML folders, Flipper Zero animation assets, and many archive types are normalized into ordered page sequences.

What It Reads

  • Books and document formats: PDF, EPUB, MOBI, AZW, AZW4, FB2, XPS/OXPS, HTML, WebArchive, MHTML, RTF, RTFD, DOC, DOCX, Word XML, OpenDocument text, YAML, and PPT text extraction.
  • Comics and page archives: CBZ, ZIP, ZIPX, CBR, RAR, CB7, 7z, CBT, TAR, .tar.gz, .tar.bz2, .tar.xz, .tar.lzma, .tar.Z, and the usual shorthand wrappers like tgz, tbz2, txz, tlz, and taz.
  • Screenplays: Fountain, Final Draft FDX, Fade In, Celtx, ASTX, and Highland.
  • Music and animated visual formats: MusicXML, MXL, APNG, GIF, PSD, PSB, YAML page collections, and Flipper Zero animation folders or ZIPs.
  • Media and 3D: standard macOS audio and video formats, native WebM, Matroska video and audio (.mkv, .mka), and 3D assets such as USD, USDZ, OBJ, PLY, STL, SCN, DAE, and Alembic.

Reader Capabilities

  • Searchable bundled libraries for e-books, music scores, and E. E. Cummings poem collections.
  • Reader themes, bundled fonts, dark mode, and a switch to respect original document fonts.
  • Read-aloud using macOS speech voices with adjustable rate, pitch, volume, and voice selection.
  • Built-in MusicXML playback through a native MIDI timeline audio synthesizer.
  • Native WebM and Matroska playback, local live captions, volume controls, and frame capture.
  • Native 3D preview with orbit controls, rotation shortcuts, and zoom.

Seamless Clip

Seamless Clip is a macOS clip editor built around one idea: trimming and rearranging video should stay as close to the original media as possible, especially for files most desktop editors still treat as second-class citizens.

What Makes Seamless Clip Different

Native Matroska and WebM handling

Seamless Clip does not treat mkv and webm as awkward imports that must be transcoded before anything useful can happen. It has native Matroska/WebM parsing, native VP9 playback paths, native keyframe discovery, native waveform fallback, native thumbnail generation fallback, and native lossless segment export for supported Matroska/WebM sources.

That matters because the app can work directly with containers and codecs that are usually pushed through a conversion step first.

Lossless export is the default mindset

For regular AVFoundation-compatible media, Seamless Clip uses passthrough export whenever possible. For Matroska/WebM sources it can build new container output directly from the original packet structure instead of re-encoding the whole file.

The result is an editor aimed at making cuts without turning every export into a quality tradeoff.

One timeline, multiple ways to read the footage

The timeline is not just a bar with in/out points. It can layer:

  • waveform bands
  • frame-strip thumbnails
  • keyframe markers
  • hover time inspection
  • zoomed and overview navigation

This gives you visual, audio, and codec-structure context in the same editing surface, which is unusually useful for finding clean cut points quickly.

Keyframe-aware navigation for precise cuts

Seamless Clip supports:

  • frame stepping
  • keyframe stepping
  • direct timecode seek
  • segment looping
  • 1-second and 5-second jumps
  • jump-to-start/end controls

That combination makes it feel closer to a focused clip bench than a simplified consumer trimmer.

Segments and markers live in the same workflow

A timeline item can be a true clip or a zero-duration marker. You can switch between those modes, rename items, tag them, duplicate them, bulk-select them, filter by type, search by label/tag, and invert clip selections into the gaps between segments.

That makes Seamless Clip useful not just for cutting media, but for logging and shaping a rough edit structure before export.

Stream-aware export

Seamless Clip exposes video, audio, and subtitle streams as selectable export targets. Instead of exporting whatever tracks happen to survive a generic pipeline, you can explicitly decide which streams travel with the result.

This is especially important for multi-track sources where the container layout is part of the asset, not accidental metadata.

Practical output beyond video files

The same segment data can be exported as:

  • clip output media
  • segment CSV
  • YouTube chapter text
  • captured PNG stills from the current frame

It also imports segments from CSV, so the app can move between logging, editing, and publishing workflows instead of trapping decisions inside one UI.

Video Grid

Video Grid is a macOS app that turns a video into a clean thumbnail sheet you can save and share. Open a video, let the app pull frames from across the timeline, adjust the look if you want, and export a finished image.

It is built for people who need a fast visual summary of a video: editors, archivists, reviewers, researchers, collectors, and anyone making contact sheets.

What Makes Video Grid Unique?

Most thumbnail tools stop at "grab some frames." Video Grid goes further:

  • It keeps everything local on your Mac. Your video is not uploaded to a server.
  • It makes a finished contact sheet, not just a folder of random stills.
  • It shows useful video details in the header, including resolution, runtime, frame rate, codec, bitrate, and file size.
  • It lets you fix individual frames after generation, so you are not stuck with the first automatic result.
  • It includes built-in style presets, font selection, timestamp controls, and color controls, so the export looks presentable without extra editing.
  • It supports common formats and also handles MKV and WebM well, which many lightweight tools ignore.

In short: Video Grid is meant to produce something you can actually use, not just something technically extracted.

What You Can Do

  • Open a video file or drag one in from Finder
  • Generate a grid of evenly spaced thumbnails
  • Choose how many rows and columns you want
  • Change the output scale to balance detail and file size
  • Rename the title shown on the exported sheet
  • Apply built-in color presets or pick your own colors
  • Choose a font from your system fonts
  • Show or hide timestamps
  • Add rounded corners and adjust spacing
  • Fine-tune any thumbnail by choosing a better moment
  • Add custom text to individual frames
  • Reorder thumbnails by dragging them
  • Export as PNG, JPEG, or HEIC

Video Crosshatch

VideoCrosshatch is a macOS app for turning ordinary video into stylized, graphic-looking motion. You can preview a single processed frame, adjust the look until it feels right, then export the full result as a video, image sequence, or animated PNG.

What Makes VideoCrosshatch Unique?

Most video stylizing tools make you guess, export, wait, and repeat. VideoCrosshatch is built around a faster workflow:

  • You can scrub to any frame and generate a one-frame preview before committing to a full export.
  • It combines visual effects, color treatments, and audio effects in one app instead of making you jump between tools.
  • It includes built-in cleanup tools like black bar removal, reframing presets, and optional AI interpolation/upscaling.
  • It feels like a native Mac app, not a collection of scripts.

In practice, that means you can experiment quickly and make creative decisions with much less waiting.

What You Can Do

  • Apply 50+ stylized video looks, including crosshatch, sketch, dot-matrix, contour, woodcut, radial, and more experimental patterns
  • Add audio treatments such as voice cleanup, loudness normalization, lo-fi, robotic, reverb, and other character effects
  • Tint the final image with color filters
  • Remove horizontal or vertical black bars automatically
  • Reframe exports for original, square, widescreen, or TikTok-style vertical output
  • Export a full movie, an image sequence, or an animated PNG
  • Download web video in the app's separate Video Downloader mode

How It Works

  1. Open a video.
  2. Scrub to a frame you care about.
  3. Click Generate Preview.
  4. Adjust the effect, color, audio, and export settings.
  5. Export when you're happy with the preview.

This preview-first workflow is the main reason the app is fast to use creatively.

Main Features

Video Filter mode

This is the main editing mode. It gives you:

  • side-by-side source and preview panels
  • searchable effect pickers
  • audio effect controls
  • brightness, saturation, contrast, and sharpness controls
  • frame range export
  • frame interpolation
  • AI upscaling
  • export progress with FPS and time remaining
Video Downloader mode

If you want to save video from supported sites, the app also includes a downloader mode with optional audio-only export and format conversion.

Scrupulous

Scrupulous is a native macOS writing app for people who want a clean drafting tool without giving up structure, preview, or print control. It works with both Markdown and Fountain, so you can write notes, long-form documents, and screenplays in one place.

The app is built around a simple idea: plain-text writing should still feel serious, polished, and pleasant to use.

What Makes Scrupulous Unique?

Most writing apps make you choose between a plain-text editor, a screenplay tool, and a heavy document app. Scrupulous sits in the middle.

  • It is a real Mac app, not a web app in a wrapper. Opening files, saving, printing, fonts, window behavior, and text editing are native.
  • It supports both Markdown and Fountain. You can write structured prose and screenplays without switching to a different application.
  • It gives you a live page-style preview while you write. Your draft stays in plain text, but you can instantly see it as a screenplay, manuscript, novel page, MLA report, or plain text printout.
  • It includes /Quick Reference, a built-in side panel for short answers, definitions, wording help, and writing nudges. When available, it uses Apple's on-device language model instead of sending your request to a website.
  • It keeps the editor useful for long documents. You get a live navigator, screenplay-aware statistics, PDF export, print support, and theme customization without turning the app into a cluttered word processor.

In short: Scrupulous is for writers who like the simplicity of plain text but still want the feeling of a dedicated writing studio.

What You Can Do

  • Create, open, and save .md and .fountain files
  • Switch between writing view and preview view
  • Use document templates such as Modern Standard, Screenplay, Manuscript, Novel, MLA Report, and Plain Text
  • Print your document or export it as a PDF
  • Use a live navigator to jump through headings, sections, and scenes
  • View live statistics such as word count, estimated pages, scene counts, and dialogue distribution
  • Customize the app's color theme
  • Use inline formatting commands for common Markdown and Fountain actions

Why Writers May Like It

  • Plain text stays at the center, so your files remain readable and portable
  • Screenplay writing is treated as a first-class mode, not an afterthought
  • Preview is built for page rhythm and print layout, not just styled text on a screen
  • The interface stays focused instead of feeling like a general-purpose office suite

Reader Bot

Reader Bot is a macOS app that turns text into natural-sounding speech using Piper voice models.

The important part: it runs on your Mac, not in the cloud. You can paste in text, choose a voice, listen immediately, and export the result as a .wav file.

What Makes Reader Bot Unique

Most text-to-speech apps are built around one of two ideas:

  • use the system voices that come with your device
  • send your text to an online service

Reader Bot takes a different approach.

  • It uses local Piper voices, so your text can stay on your machine.
  • It gives you direct control over the voice model instead of hiding everything behind one Play button.
  • It supports multi-speaker voice models, so some voices let you switch between different speaker tracks.
  • It can export speech as audio, which makes it useful for drafts, voiceovers, and accessibility workflows.

In short: Reader Bot is for people who want more control and more privacy than a typical reader app.

What You Can Do

  • Paste or type text and hear it read aloud
  • Choose from installed Piper voices
  • Adjust voice behavior with settings like noise, length, and volume
  • Switch speakers when a voice model supports more than one
  • Save generated speech as a .wav file

Who It Is For

Reader Bot is a good fit if you want to:

  • listen to writing drafts out loud
  • preview Piper voices on macOS
  • create local voice clips without using a web service
  • keep sensitive text off third-party servers
